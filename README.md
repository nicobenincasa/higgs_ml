# Higgs ML

Machine-learning classification of simulated Higgs-boson events.

This project is an introduction to supervised machine learning applied to particle-physics data.

## Goals

* Explore a particle-physics dataset
* Build a simple classification baseline
* Train a gradient-boosted decision-tree classifier
* Train a small neural network
* Compare the models using ROC curves and ROC-AUC
* Investigate feature importance
